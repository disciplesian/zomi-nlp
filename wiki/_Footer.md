## About this project

**Zomi-NLP** is an open-source project for building reproducible datasets, tokenizers, and language models for Zomi (Tedim Chin, ISO 639-3 `ctd`). This wiki shares project documentation, workflows, and guidance for contributors and users.

- [Releases](https://github.com/disciplesian/zomi-nlp/releases)

## Contributions and feedback

Bug reports, ideas, and documentation improvements are welcome. Please [review the contribution guide](Contributing) and check existing issues before starting substantial work; use the [issue tracker](https://github.com/disciplesian/zomi-nlp/issues) to report a problem or suggest an improvement, or submit a pull request for a proposed change. Please communicate respectfully and include enough detail to make feedback actionable.
